# Khalid's Portfolio — GitHub Pages

## Before publishing
Place your portrait image in `assets/` and name it exactly `portrait.png`.

## Publish
1. Create a public GitHub repository named `portfolio`.
2. Upload the contents of this folder to the repository root.
3. Open Settings → Pages.
4. Select `Deploy from a branch`, branch `main`, folder `/(root)`, then Save.
5. Your expected URL is `https://KhalidMohamed37.github.io/portfolio/`.
